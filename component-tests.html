Living inventory

Component tests are intentionally small.

They sit between unit tests and the full application: enough real integration to exercise a subsystem, without requiring the entire cockpit stack. Legacy CLIs remain in the source tree but are omitted from the primary matrix so new contributors are not sent enthusiastically toward yesterday.
